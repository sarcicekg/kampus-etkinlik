# Kampüs Etkinlikleri - Sprint 1

Bu proje, Kampüs Etkinlikleri uygulamasının HTML5 semantic etiketleri kullanılarak oluşturulmuş ilk sürümüdür (Sprint 1).

## Özellikler
- Hiçbir CSS ve JavaScript kullanılmadan yalnızca HTML5 semantic etiketleri ile inşa edilmiştir.
- Ana Sayfa, Detay, Ekleme ve Güncelleme sayfalarını içerir.
- Form alanları görünür `label` etiketleri ve `required` doğrulama öznitelikleri ile yapılandırılmıştır.
